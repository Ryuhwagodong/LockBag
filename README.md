# LockBag

### Touch ID로 여는 나만의 앱 공간.

LockBag은 Mac에서 선택한 앱에 접근할 때 Touch ID 인증을 요청하는 macOS 앱입니다. 익숙한 macOS 인터페이스 안에서 개인 공간을 조금 더 편안하게 관리하는 경험을 만들고 있습니다.

## 주요 기능

- **Touch ID 인증** — 보호된 앱으로 돌아오면 시스템 인증창이 자동으로 나타납니다.
- **자동 재잠금** — 다른 앱으로 이동하면 다시 인증을 요청합니다.
- **화면 블러** — 인증 중에는 앱을 숨기는 대신 화면을 흐리게 가립니다.
- **macOS 디자인** — 시스템 기본 컨트롤과 라이트·다크 모드를 지원합니다.
- **메뉴 막대** — 보호 상태를 관리하고 앱을 다시 잠글 수 있습니다.

## 개발 상태

현재 개발 중인 프로토타입입니다. 정식 출시 일정과 다운로드는 준비가 완료되면 이 페이지에서 안내합니다.

현재 구현은 화면을 가리는 방식이며, 운영체제 수준의 앱 실행 차단 기능은 아닙니다. 앱의 백그라운드 작업이나 알림까지 차단하지 않으며, LockBag을 종료하면 보호가 중단됩니다.
